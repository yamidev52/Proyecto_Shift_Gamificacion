# Alcance y medición del producto

## Objetivos

Reducir la deserción relativa en 25% frente a una cohorte comparable y alcanzar NPS 60–70. No se puede atribuir ese efecto al software sin datos de un piloto.

| Funcionalidad                 | Hipótesis de retención                               | Señal disponible                                                        |
| ----------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------------- |
| Ruta vertical y panel lateral | Reducir la dificultad de encontrar el siguiente paso | Inicio y finalización de misión                                         |
| Píldoras con caso laboral     | Mejorar relevancia percibida                         | Finalización y avance de curso                                          |
| Meta flexible y congeladores  | Permitir pausas sin castigar la carga laboral        | Meta elegida, actividad semanal y protección usada                      |
| Recompensas                   | Relacionar el esfuerzo con beneficios prácticos      | Canjes y solicitudes                                                    |
| Copiloto contextual           | Dar una acción inmediata según tiempo y contexto     | Interacciones de práctica (a instrumentar para analítica del proveedor) |
| Gremio y perfil               | Crear pertenencia y ayuda entre pares                | Retos, respuestas y votos de valor                                      |
| Encuesta NPS                  | Recoger fricción y satisfacción                      | Última respuesta 0–10 por estudiante                                    |

## Definiciones para el piloto

- **Deserción:** acordar con el equipo académico la ventana de inactividad o baja formal. No usar la falta de una conexión diaria como señal de abandono.
- **Reducción relativa:** `(tasa_base - tasa_piloto) / tasa_base`. Ejemplo: de 20% a 15% representa una mejora relativa de 25%, no 25 puntos porcentuales.
- **NPS:** porcentaje de promotores (9–10) menos porcentaje de detractores (0–6); 7–8 son pasivos. Reportar tamaño de muestra y tasa de respuesta. La demo recoge la respuesta, no presume un NPS ya logrado.
- **Tiempo de progreso:** suma de la duración estimada de misiones completadas; no equivale a tiempo efectivamente dedicado.
- **Aporte valioso:** una respuesta marcada como útil por otro usuario, con un voto máximo por pareja usuario/respuesta.

## Antes de un piloto real

Validar contenido, accesibilidad con usuarios adultos, políticas de canje, moderación, privacidad y respaldo de datos. Reemplazar las cuentas y avances de demostración. Conectar los servicios institucionales descritos en CANVAS.md. Diseñar la comparación de cohortes y la cadencia de encuesta antes de interpretar efectos de retención.
